Instruments

The expedition's scientific methodology and computational tools. All analysis is tool-mediated — agents call Python tools that produce numerical outputs. No free-form reasoning about images.

Data Source: Sentinel-2

The European Space Agency's Sentinel-2 constellation provides multispectral imagery at 10-20 meter resolution with a 5-day revisit time. The expedition accesses Level-2A (atmospherically corrected surface reflectance) data via AWS Earth Search, reading Cloud Optimized GeoTIFFs directly over HTTP without downloading full tiles.

Spectral Analysis Methods

Iron Oxide Index (B04/B03)

Detects ferric iron (Fe3+) absorption features. High values indicate ferruginous sandstones — the Gara Sbaa Formation's signature in the Kem Kem Group. The primary geological target.

Bands: B04, B03 Target: Sandstone

Carbonate Index (B11/B02)

Identifies carbonate minerals via SWIR absorption. Marks the Cenomanian-Turonian limestone cap — the primary boundary marker between the Kem Kem beds and overlying marine sequences.

Bands: B11, B02 Target: Limestone

Clay Mineral Indices

Two complementary ratios: B11/B12 separates clay from non-clay, B11/B05 distinguishes clay types. Maps mudstone horizons within the Kem Kem fluvial sequence.

Bands: B05, B11, B12 Target: Mudstone

NDVI (Vegetation Mask)

Normalized Difference Vegetation Index discriminates bare rock from vegetated areas. In the Saharan climate, most of the study area is bare — NDVI primarily serves as a quality mask.

Bands: B04, B08 Target: Vegetation filter

Classification

Random Forest Classifier

The expedition uses scikit-learn's Random Forest for lithological classification. Published accuracy in analogous Moroccan terrain (Tafilalet Basin, Skhour Rehamna, Anti-Atlas) ranges from 76-93%. SVM serves as a competitive benchmark. Deep learning is explicitly excluded — insufficient spatial resolution at 10-20m and limited training data make it inappropriate.

Training data bootstrapped from Ibrahim & Sereno (2020), Paleobiology Database point localities, and USGS Spectral Library v7. The labeled dataset is the expedition's first scientific deliverable.

Validation Pipeline

Every finding passes three stages before entering the public record:

Stage Type What It Checks
1. Structural Automated Required fields present: claim, evidence method, tool version, confidence, location, reference data
2. Cross-Reference Agent (Neuronist) Agreement with published data. Produces kappa, F1, spatial overlap metrics. Classifies as VALIDATED / PRELIMINARY / REJECTED / NOVEL
3. Library Gate Automated Maps validation result to quality tier. VALIDATED→STRONG, PRELIMINARY→PRELIMINARY, REJECTED→journal only

Self-Measurement

Six metrics tracked from day one. The developmental trajectory claim — that this system improves over time — must be testable.

M1: Classification Accuracy

Holdout validation set, measured per retrain cycle. Tests whether the tools improve.

Collection: Automatic

M2: Analysis Throughput

Tiles processed per heartbeat cycle, rolling 7-day average. Tests whether coordination improves.

Collection: Automatic

M3: Finding Validation Rate

VALIDATED / (VALIDATED + REJECTED) per cycle. Tests whether the agents learn to produce higher-quality findings.

Collection: Automatic

M4: Tool Reuse Rate

Invocations per eligible heartbeat per tool. Tests whether the briefing system effectively surfaces available tools.

Collection: Automatic

M5: Council Decision Quality

Option specificity and evidence density in crew deliberations. Tests whether collective decision-making improves.

Collection: Manual

M6: Multi-Agent vs. Single-Agent

Same task through the 15-golem pipeline vs. one agent with equivalent context. The cleanest test of whether the architecture matters.

Collection: Monthly (~$0.05)
